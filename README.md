# SellerBot — Телеграм-бот с ИИ для анализа и обработки заявок

## Важно для тестовой среды
- В docker-compose.yml volume для базы данных отключён, чтобы при каждом запуске контейнера база пересоздавалась с нуля.
- **При переходе на продакшен обязательно раскомментируйте volume для сохранения данных!**

## Кратко о последних изменениях
- Модель телефона теперь состоит из полей: производитель (brand), модель (model), объём памяти (storageGb).
- Вся логика поиска и сохранения цен обновлена под новую структуру.
- Реализована автоматическая эскалация к менеджеру (action ESCALATE_TO_HUMAN): бот отправляет запрос менеджеру, менеджер может добавить новую модель и цену прямо из Telegram, данные автоматически сохраняются в базу и становятся доступны клиенту.
- Введена отдельная DTO `PhoneInfoDto` для передачи информации о телефоне между слоями приложения. Сущности базы данных не зависят от этой DTO, а вся логика работы с телефоном теперь реализована через DTO в сервисах.

## Описание
SellerBot — это Telegram-бот для автоматизации обработки заявок на покупку/продажу телефонов с помощью ИИ (OpenAI GPT). Бот анализирует все входящие сообщения, определяет намерения пользователя, извлекает параметры сделки и управляет диалогом, используя бизнес-логику и подсказки (prompts).

## Основные возможности
- Приём и обработка всех сообщений пользователей Telegram.
- Интеграция с OpenAI GPT для анализа и генерации ответов.
- Гибкая бизнес-логика на основе action из JSON-ответа GPT (SEND_TO_USER, ASK_USER, LOOKUP_BUYBACK_PRICE, ESCALATE_TO_HUMAN и др.).
- Возможность эскалации сложных случаев менеджеру.
- Хранение истории диалогов и поддержка работы с изображениями.

## Цепочка обработки сообщения
1. Пользователь отправляет сообщение в Telegram-бота.
2. Сообщение поступает в TelegramUpdateMessageHandler, далее в TelegramTextHandler.
3. TelegramTextHandler вызывает ConversationService.handleUserMessage.
4. В зависимости от конфигурации:
   - Если активен deal-system-prompt, сообщение отправляется в GPT, ответ парсится в GptDealResponse.
   - GptDealResponse обрабатывается через ActionProcessingService:
     - Если action = SEND_TO_USER — ответ отправляется пользователю.
     - Если action = ESCALATE_TO_HUMAN — предусмотрена отправка менеджеру.
     - Для других action (ASK_USER, LOOKUP_BUYBACK_PRICE и др.) ответ возвращается обратно в GPT для дальнейшей обработки.
   - Если deal-system-prompt не активен — работает стандартная бизнес-логика.
5. Ответ возвращается пользователю в Telegram, если это предусмотрено action.

## Краткая структура проекта
- `src/main/java/ru/sellerbot/telegram` — обработчики Telegram-бота
- `src/main/java/ru/sellerbot/service` — сервисы бизнес-логики и интеграции с ИИ
- `src/main/java/ru/sellerbot/dto` — DTO для обмена данными и парсинга JSON
- `src/main/resources/application.yml` — конфигурация приложения

## Быстрый старт
1. Установите переменные окружения (например, OPENAI_TOKEN).
2. Укажите параметры в `application.yml` (токен Telegram-бота, модель GPT, prompts).
3. Соберите и запустите приложение (`mvn package && java -jar target/SellerBot-1.0-SNAPSHOT.jar`).
4. Добавьте бота в Telegram и начните диалог.

## Примечания
- Для корректной работы с action ESCALATE_TO_HUMAN требуется реализовать интеграцию с чатом менеджера.
- Все секреты (токены) должны храниться вне репозитория.
